# 求职备考笔记工坊

用于制作国央企求职、军文备考与知识类小红书笔记的 Codex skill。

把原图、文档或新主题整理成一套可交付的内容：**封面与内页图片、对应标题和文案 TXT、编号文件夹、预览页面及 ZIP 文件包**。

## 封面测试效果

![AI选岗封面：左右竖排大字与中央插画人物](examples/ai-career-cover.png)

本张测试抽取 **S04：左右竖排大字＋中央人物**。

- 主题：AI专业，央国企岗位怎么选。
- 主视觉：黄白竖排“专业”“岗位”，中央职业装插画人物。
- 辅助文字：央国企求职、AI选岗、先看匹配度。
- 无Logo，人物为AI生成插画，不是真实教师照片。
- 图片由内置图像生成工具制作。参考构图用于风格探索，不代表任何招聘机构或人物背书。

## 支持的三种用法

1. **原资料重排**：读取用户提供的图片或文档，保留实质内容，重新设计信息层级和版式。
2. **新内容生产**：根据新主题查阅资料，核查招聘时间、政策及适用条件，再制作对应笔记。
3. **补充内容融合**：将补充资料融入已有文章，同步调整标题、封面、内页和配套文案。

## 五种随机封面风格

| 编号 | 结构 | 适合内容 |
|---|---|---|
| S01 | 大字包围主体＋侧边关键词 | 知识拆解、概念入门 |
| S02 | 三项对勾清单＋底部主题标语 | 准备事项、报考材料、流程 |
| S03 | 顶部类目＋大标题＋底部方法句 | 学科方法、题型、岗位辨析 |
| S04 | 左右竖排大词＋中央人物 | 选岗逻辑、面试表达、职业认知 |
| S05 | 粗标题＋人物白边＋三条色块 | 学习法、复盘、知识清单 |

制作时先判断主题适配，再随机轮换；避免连续使用同一版式。继续修改同一项目时保留已抽取的风格。参考图里的名人背书、功效数字和保证性表述不会被当作模板事实。

## 安装

将仓库中的 `skills/career-study-notes` 文件夹复制到个人 Codex 技能目录，使入口位于 `~/.codex/skills/career-study-notes/SKILL.md`。

个人技能目录通常为 `~/.codex/skills`。安装后在可用技能列表中查找“求职备考笔记工坊”。

## 输出与检查

默认3:4竖版、1080×1440、无Logo。内容多时允许增加页数，优先完整与可读。每篇保留资料来源，模糊原图不猜字；是否保留附件由用户确认。

交付检查脚本需要 Python 和 Pillow：

```text
python skills/career-study-notes/scripts/validate_delivery.py <项目根目录>
python skills/career-study-notes/scripts/choose_cover_styles.py --count 15 --seed 我的项目
```

检查脚本覆盖图片尺寸、文件清单、编号和标题对应等结构问题，不代替事实核查与视觉检查。招聘日期、薪资及条件需以相应企业当次正式公告为准。素材制作不包含自动发布到社交平台。

## 素材说明

`skills/career-study-notes/assets/cover-references` 中的图片是用户提供的版式参考，原有权利不因收录而转移；不应直接当作本人肖像、教师照片或品牌授权素材发布。实际制作应使用可合法使用的人物素材或明确标识的生成插画。
